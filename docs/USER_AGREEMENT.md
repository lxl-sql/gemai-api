## 一、定义与解释

1.1 **本平台 / 本服务**：指基于 New API 开源项目部署运营的 AI API 网关服务，包括但不限于 Web 控制台、API 接口、相关文档及配套服务。

1.2 **用户 / 您**：指注册、登录、使用本服务的个人、法人或其他组织。

1.3 **账户**：指您通过注册流程（包括但不限于邮箱注册、第三方 OAuth 授权登录、通行密钥等方式）获得的本平台使用凭证。

1.4 **API 令牌（Token）**：指您在本平台创建的、用于调用 API 接口的访问密钥（通常以 `sk-` 开头）。

1.5 **额度（Quota）**：指您账户中可用于抵扣 API 调用费用的计费单位，可通过充值、兑换码、邀请奖励等方式获得。

1.6 **上游服务商**：指本平台所对接的第三方 AI 模型服务提供方，包括但不限于 OpenAI、Anthropic、Google、阿里云、字节跳动等。

1.7 **模型内容**：指您通过本服务向 AI 模型提交的输入内容（Prompt）以及模型返回的输出内容（Completion），包括文本、图像、音频等形式。

## 三、服务内容说明

3.1 本服务的主要功能包括：

- **统一 API 网关**：聚合多家上游 AI 服务商的模型接口，提供兼容 OpenAI、Anthropic（Claude）、Google（Gemini）等格式的统一调用入口；
- **令牌管理**：支持创建、编辑、禁用、删除 API 令牌，并可对令牌设置额度上限、过期时间、模型范围、IP 白名单等限制；
- **额度计费**：按照模型定价（含按 Token 计费、按次计费、分层/动态计费等模式）对 API 调用进行额度扣减与结算；
- **用量统计**：提供调用日志、消费明细、用量仪表盘等数据查询功能；
- **账户体系**：支持邮箱注册、第三方 OAuth 登录、通行密钥（Passkey）、两步验证等账户安全功能。

3.2 本服务为**技术中转与管理服务**。模型的实际推理能力由上游服务商提供，本平台不对模型输出内容的生成过程进行实质性控制。

3.3 本平台有权根据业务发展需要，增加、调整、暂停或下线部分模型、功能或服务，并以公告等合理方式通知用户。

## 六、充值、额度与计费规则

6.1 **额度获取**：您可以通过在线充值、兑换码（卡密）、邀请奖励、管理员发放等方式获得额度。

6.2 **计费方式**：

- API 调用按照平台公示的模型价格进行计费，计费维度可能包括输入/输出 Token 数量、调用次数、缓存命中、思维链 Token、图像/音频处理量等；
- 部分模型可能采用分层定价或动态表达式计费，具体以控制台"模型价格"页面公示为准；
- 平台公示价格可能随上游服务商价格调整而变动，调整后的价格自公示时起对新发生的调用生效，**不溯及既往**。

6.3 **预扣与结算**：部分调用会先进行额度预扣，调用完成后按实际用量结算，多退少补。因网络中断等原因导致调用异常的，以平台日志记录的实际结算结果为准。

6.4 **退款政策**：

- 已充值的额度原则上**不支持退款**，法律法规另有规定或平台规则另有约定的除外；
- 通过兑换码、邀请奖励、活动赠送等方式获得的免费额度不可提现、不可转让、不可退款；
- 因本平台重大服务故障导致额度被错误扣减的，您可提交工单申请核查，经核实后本平台将补回相应额度。

6.5 **额度有效期**：除平台规则另有约定外，付费额度长期有效；赠送额度的有效期以发放时的说明为准。

6.6 **欠费处理**：账户额度不足或为负时，本平台有权暂停相关 API 调用服务，直至您补足额度。
