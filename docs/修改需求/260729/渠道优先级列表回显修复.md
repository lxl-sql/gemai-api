# 渠道优先级列表回显修复

日期：2026-07-29

## 修复范围

本次仅修复渠道列表内联编辑优先级和权重时的前端状态问题，不调整后端接口、渠道排序规则或页面布局。

1. 异步保存期间保留刚提交的数值，避免退出编辑态后立即回显旧值。
2. 当前单元格保存期间禁止重复编辑；保存失败时恢复服务端原值。
3. 保存成功后等待渠道列表刷新完成，再结束单元格保存状态。
4. 普通渠道行和标签聚合行使用不同的稳定行 ID，避免优先级排序变化后复用错误的输入状态。

- 标签批量确认使用的同步回调仍恢复受控值。

## 复审补充

复审发现多个渠道同时保存时，后一次列表刷新可能取消前一次刷新；刷新失败时也可能暂时没有新的服务端回显。现已补充：

- 保存接口已成功但列表仍是旧数据时，继续显示最后一次成功提交值。
- 后续再次编辑失败时，恢复到最后一次成功提交值，而不是更早的服务端旧值。
- 服务端后续返回提交值或其他权威值时，控件继续正常同步。

新增回归覆盖：列表没有刷新到新值时保留成功提交值，并在下一次保存失败后恢复该值。
