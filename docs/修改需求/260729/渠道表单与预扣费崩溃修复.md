# 渠道表单与预扣费崩溃修复

日期：2026-07-29

## 修改范围

- 修正渠道新增与编辑抽屉中 API Key 说明区域的无效 HTML 嵌套，避免 React hydration 警告。
- 预扣费发生在渠道元数据初始化之前时，从当前请求上下文读取已选渠道 ID，避免空指针崩溃。
- 付费请求派发前使用本次所选渠道刷新渠道元数据，避免派发标记再次解引用未初始化数据。
- 保持渠道重试和最终派发时的既有渠道记录更新行为不变。

## 验收

- 打开渠道新增或编辑抽屉，浏览器控制台不再出现 `<div>` 位于 `<p>` 内的 DOM nesting 警告。
- 在渠道元数据尚未初始化的请求中执行钱包预扣费，不发生 panic，且预扣费记录包含当前请求选择的渠道 ID。
- 付费请求在渠道元数据尚未初始化时能够安全标记派发，并记录当前渠道 ID。
- 预扣费失败后的退款行为保持同步、持久并可重复验证。
