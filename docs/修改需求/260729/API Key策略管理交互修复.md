# API Key 策略管理交互修复

日期：2026-07-29

## 修改范围

- 安全策略列表改为紧凑表格，新建和编辑统一使用弹窗。
- 新建策略只允许选择用户分组或指定用户；平台默认策略从现有行编辑。
- 所有用户组均已有策略时，新建弹窗默认切换到指定用户。
- 编辑时锁定策略范围和目标，避免修改范围后遗留旧策略。
- 新建策略使用仅创建语义；同一目标已存在策略时不会被意外覆盖。
- Base UI 下拉框补充本地化选项映射，不再显示 `platform`、`observe` 等内部值。
- 用户管理菜单为 Root 增加「API Key 安全策略」，可直接设置指定用户策略或恢复继承。
- 指定用户默认不新增记录，按用户分组、平台、内置策略的顺序继承。
- 指定用户尚无覆盖策略时，切换到自定义会以当前继承策略为基础；仅有内置回退时使用系统默认值回填。
- 恢复继承始终执行幂等删除，避免页面数据过期时遗漏清理用户策略。
- 复用现有 `token_security_profiles` 表，不新增用户字段或数据库迁移。
- 修正相关多语言文案及繁体中文简繁混用。

## 行为说明

指定用户策略仍然是该用户每个 API Key 的管理员安全边界，不是该用户所有
API Key 的合计 RPM。恢复继承会删除指定用户覆盖策略，用户随后优先继承所属
分组策略，没有分组策略时继承平台策略。

## 验收

- 已选策略范围和风险响应显示本地化名称。
- 新建策略不会覆盖平台默认策略。
- 并发新建同一目标策略时，数据库唯一约束会保留原策略。
- 编辑策略不能改变范围或目标。
- 多个策略以紧凑表格展示。
- Root 可以从用户行操作中设置或恢复指定用户策略。
- 恢复继承在策略已不存在时也可安全重复执行。
- 用户策略回填测试覆盖已有用户策略、分组继承和内置默认值三种情况。
- 所有语言缺失键和多余键均为 0。
