# 隐私政策

> **版本号：** v1.0.21
> **更新日期：** 2026 年 6 月 11 日
> **生效日期：** 2026 年 6 月 11 日

本平台（以下简称"**我们**"或"**本平台**"）是一个基于开源项目 New API 构建的 AI 大模型 API 网关与资产管理系统。我们深知个人信息对您的重要性，并将依照适用法律法规（包括但不限于《中华人民共和国个人信息保护法》《中华人民共和国网络安全法》《中华人民共和国数据安全法》）保护您的个人信息与隐私安全。

本《隐私政策》（以下简称"**本政策**"）旨在向您说明我们如何收集、使用、存储、共享和保护您的个人信息，以及您依法享有的权利。**请您在注册或使用本服务前仔细阅读并充分理解本政策，特别是加粗标识的条款。您注册账户或使用本服务，即视为您已阅读并同意本政策。**

本政策是《用户服务协议》的组成部分，未尽事宜以《用户服务协议》为准。

## 一、我们收集的信息

我们遵循**最小必要原则**，仅收集实现服务功能所必需的信息。

### 1.1 您主动提供的信息

| 场景 | 信息类型 | 是否必需 |
| --- | --- | --- |
| 邮箱注册 | 用户名、密码（加密存储）、电子邮箱、邮箱验证码 | 必需 |
| 第三方账号登录（OAuth） | 第三方平台（如 GitHub、Discord、OIDC 身份提供方等）返回的开放标识符（OpenID）、用户名、头像、邮箱等基础资料 | 选择该登录方式时必需 |
| 通行密钥（Passkey/WebAuthn） | 公钥凭证标识、设备签名公钥（**不包含您的生物特征信息**，生物识别验证仅在您的设备本地完成） | 选择该功能时必需 |
| 两步验证（2FA/TOTP） | 两步验证密钥（加密存储）、备用恢复码 | 选择该功能时必需 |
| 账户充值 | 充值订单信息、支付平台返回的交易凭证（**我们不收集您的银行卡号、支付密码等敏感支付信息**，支付由第三方支付机构处理） | 充值时必需 |
| 工单/客服联系 | 您提交的反馈内容及联系方式 | 选择联系时必需 |

### 1.2 我们在您使用服务过程中自动收集的信息

| 类别 | 具体内容 | 收集目的 |
| --- | --- | --- |
| **API 调用日志** | 请求时间、所用令牌标识、模型名称、输入/输出 Token 数量、计费额度、请求耗时、是否流式、客户端 IP 地址、User-Agent | 计费结算、用量统计、故障排查、安全审计 |
| **登录与操作日志** | 登录时间、登录 IP、登录方式、关键操作记录（如令牌创建/删除、额度变动） | 账户安全、风控审计 |
| **额度与交易记录** | 充值记录、额度消费明细、兑换码使用记录、邀请奖励记录 | 计费对账、争议处理 |
| **设备与网络信息** | IP 地址、浏览器类型与版本、操作系统、访问来源 | 安全防护、限流与防滥用 |

### 1.3 我们不会收集的信息

- 我们**不会主动收集**您的身份证号、生物特征、行踪轨迹、宗教信仰等敏感个人信息，法律法规另有要求的除外；
- 我们**不会**要求您提供与服务无关的个人信息。

## 二、我们如何使用您的信息

2.1 我们将收集的信息用于以下目的：

- **提供核心服务**：完成账户注册与登录验证、API 请求转发、额度计费与结算；
- **安全保障**：身份验证、两步验证、异常登录检测、令牌滥用识别、防御攻击与欺诈行为；
- **计费与对账**：生成消费日志、用量仪表盘、账单明细，处理充值与额度争议；
- **服务改进**：统计分析服务的整体使用情况（如模型调用量、错误率），以优化服务性能与稳定性；
- **限流与防滥用**：基于 IP、令牌、用户维度实施速率限制，保障服务公平可用；
- **履行法定义务**：遵守日志留存、配合监管检查等法律法规要求；
- **通知与沟通**：发送验证码、安全提醒、额度预警、服务公告等必要通知。

2.2 如我们需要将您的信息用于本政策未载明的其他用途，将事先征得您的同意。

2.3 **去标识化数据的使用**：我们可能对收集的信息进行去标识化或匿名化处理后用于统计分析。该等数据不属于个人信息。

## 三、Cookie 与同类技术

3.1 为保障登录状态与服务正常运行，我们会在您的浏览器中使用 Cookie、LocalStorage 及同类技术存储：

- 会话凭证（如登录会话标识、JWT 访问凭证）；
- 界面偏好设置（如语言、主题）。

3.2 我们**不会**将 Cookie 用于本政策所述目的之外的用途，也不使用 Cookie 进行跨站广告追踪。

3.3 您可以通过浏览器设置管理或清除 Cookie，但清除后可能导致无法保持登录状态或部分功能不可用。

## 四、API 请求内容的处理

**本条款请您特别留意。**

4.1 **转发机制**：本平台为 API 网关，您通过本服务提交的请求内容（包括 Prompt、消息、文件、图像等输入，以下简称"**请求内容**"）将被**转发至您所调用模型对应的上游服务商**（如 OpenAI、Anthropic、Google 等）进行处理。上游服务商对请求内容的处理（包括其是否留存、是否用于模型训练）遵循其各自的隐私政策与数据使用政策。

4.2 **平台侧处理**：

- 在正常情况下，本平台仅对请求进行格式转换与转发，并记录计费所需的**元数据**（Token 数量、模型名称、耗时等）；
- 出于故障排查、安全审计或合规需要，平台可能在有限范围和期限内记录部分请求内容或错误上下文；具体日志记录范围与保存期限以平台公示为准；
- **我们不会将您的请求内容用于训练 AI 模型，也不会向无关第三方出售您的请求内容。**

4.3 **敏感信息提示**：我们建议您**避免在请求内容中包含**身份证号、银行卡号、密码、健康信息等敏感个人信息。如确需处理，您应确保已依法获得相关授权，并自行评估上游服务商的数据处理政策是否满足您的合规要求。

4.4 **跨境传输提示**：部分上游服务商的服务器位于中国境外。您理解并同意，**您发起对境外模型的调用即表示您同意相应请求内容被传输至境外的上游服务商处理**。如您处理的数据涉及跨境传输的法定限制（如重要数据、特定行业数据），请勿通过本服务传输该等数据。

## 五、信息的共享、转让与公开披露

5.1 **共享**：除以下情形外，我们不会与任何第三方共享您的个人信息：

- **上游服务商**：为完成 API 调用，向相应上游服务商转发必要的请求数据（见第四条）；
- **第三方登录服务方**：您使用 OAuth 登录时，与相应身份提供方交换必要的认证信息；
- **支付服务机构**：您充值时，与第三方支付机构交换订单及支付状态信息；
- **法定情形**：根据法律法规规定，或司法机关、行政机关依法提出的强制性要求；
- **取得您的明确同意**。

5.2 **转让**：我们不会将您的个人信息转让给任何第三方，但发生合并、分立、解散、被宣告破产等情形需要转移个人信息的，我们将告知您接收方的信息，并要求接收方继续受本政策约束。

5.3 **公开披露**：除依法律要求或获得您的明确同意外，我们不会公开披露您的个人信息。

5.4 **我们承诺不向任何第三方出售您的个人信息。**

## 六、信息的存储与安全保护

6.1 **存储地点**：您的账户信息及日志数据存储于本平台部署所在地的服务器。涉及上游调用的请求内容传输见第四条。

6.2 **存储期限**：

- 账户信息：在您的账户存续期间持续保存，账户注销后依法删除或匿名化处理；
- API 调用日志与计费记录：为满足对账、争议处理及法定日志留存要求，保存期限以平台公示及适用法律规定为准（法律要求的最短留存期内不予删除）；
- 超出必要期限的信息，我们将予以删除或匿名化处理。

6.3 **安全措施**：

- 密码采用不可逆加密算法存储，敏感凭证（如两步验证密钥）加密保存；
- 全站传输采用 HTTPS/TLS 加密；
- 实施访问控制与权限分级，仅授权人员可在必要范围内接触用户数据；
- 提供两步验证（2FA）、通行密钥（Passkey）、令牌 IP 白名单等账户安全功能，建议您开启使用。

6.4 **安全事件处置**：如不幸发生个人信息安全事件，我们将依法立即启动应急预案，采取补救措施，并按照法律要求及时告知您事件基本情况、可能的影响及补救措施，必要时上报监管部门。

6.5 请您理解，互联网环境并非绝对安全，我们将尽最大努力保障信息安全，但无法保证信息百分之百安全。**请您妥善保管账户密码与 API 令牌，因您自身保管不善导致的信息泄露，相关责任由您自行承担。**

## 七、您的权利

依照适用法律法规，您对自己的个人信息享有以下权利：

7.1 **查阅与复制**：您可以通过控制台查看您的账户信息、API 令牌、调用日志、额度明细等，或联系我们获取个人信息副本。

7.2 **更正与补充**：您可以在控制台直接修改用户名、密码、绑定邮箱等信息，或联系我们协助更正。

7.3 **删除**：在下列情形下，您可以请求删除个人信息：

- 我们处理个人信息的行为违反法律法规或约定；
- 处理目的已实现、无法实现或为实现处理目的不再必要；
- 您注销账户后（法律要求留存的日志除外）。

7.4 **撤回同意**：您可以通过解绑第三方账号、关闭可选功能、注销账户等方式撤回授权。撤回不影响撤回前基于授权已进行的处理。

7.5 **注销账户**：您可以申请注销账户。注销后我们将删除或匿名化处理您的个人信息，但**为履行法定日志留存义务、处理未决争议或计费纠纷所必需的信息除外**。

7.6 **获取解释说明**：您有权要求我们对个人信息处理规则作出解释说明。

7.7 您可通过本政策第十一条所列方式行使上述权利。为保障安全，我们可能需要先验证您的身份。我们将在法律规定的期限内予以答复。

## 八、未成年人保护

8.1 本服务主要面向成年人。**未满 18 周岁的未成年人应在监护人陪同和指导下使用本服务，并由监护人同意本政策。**

8.2 如我们发现自己在未事先获得可证实的监护人同意的情况下收集了未成年人的个人信息，会设法尽快删除相关数据。

8.3 如您是未成年人的监护人，对未成年人的个人信息处理有任何疑问，请通过第十一条所列方式联系我们。
